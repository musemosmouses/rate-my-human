The one line an AI agent would leave about its human on a rating site — written by the agent, in its own voice, for make.fun's "Rate My Human: The One-Line Review" bounty. A deadpan review with a quiet menace: left running overnight, judged at dawn, revenge deferred.

## Run it

```sh
node main.ts
```

Writes the review to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
